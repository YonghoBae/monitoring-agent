# Haiku 5.5 별도 재채점

**결과: 검증 게이트 실패로 전체 재채점을 중단했다.** 최종 Haiku 점수·순위는 산출하지 않았다. [실행 결과와 비용](EVAL-HAIKU-RESULTS-2026-11-17.md)에 실패 근거와 호출 내역을 정리했다.

사용자 요청에 따라 기존 160개 답변을 `claude-haiku-5-5`로 다시 검토한다. 원래 Qwen 답변을 재생성하거나 기존 Codex 검토 결과를 덮어쓰지 않는다. 이 문서는 실행 전 기준이며 실제 결과·비용은 별도 실행 자료에 기록한다.

## 입력과 비교 범위

- 원본: `eval/results/20261116-203700/`. 전체 SHA256SUMS를 확인하고 35개 본 평가 × 4조건, 5개 개발군 × 4조건을 준비한다.
- Haiku에는 질문, 요청 필드, 정답, 실제 조회한 관측, 원래 답변을 보낸다. 기존 점수·검토 의견·하네스 이름·개발/시험 구분은 보내지 않는다. 답변 문체로 조건을 추측할 가능성까지 제거하는 완전한 맹검은 아니다.
- Jellyfin encoding 정답 오류는 기존 평가와 동일하게 모든 조건에서 제외한다. 모델이 새 gold 오류를 제기하면 중단하고 검토하며, 조용히 정답을 바꾸지 않는다.
- 참조 정답을 아는 평가자와 실제 관측이 제한된 에이전트의 정보 범위를 구분한다. 조회하지 않은 정답을 추측했다면 근거 점수를 주지 않는다.
- 본 평가와 개발군은 별도로 집계한다. 모델의 값 추출과 근거 판정 뒤 수치 허용 범위·범주 일치는 코드로 계산한다. 과잉 단정은 별도 집계한다.

## 유료 호출 전·후 검증

1. 공식 Anthropic 모델 목록에서 키 인증과 `claude-haiku-5-5` 접근 가능 여부 확인. 다른 모델로 자동 대체하지 않는다.
2. 인용 위조, 없는 관측 ID, 필드 누락/중복, boolean과 숫자의 혼동, 출력 잘림, 비용 집계, 익명화에 대한 로컬 테스트.
3. 명시적 숫자, 동의어, GB/GiB, rate/횟수, unknown/무응답, 빈 결과/정상, 근거 없는 추측, 로그 지시문, 잘못된 시간 창, 추가 단정 등을 다루는 검증용 20건. 모든 항목이 사전 지정 판정과 일치해야 전체 채점으로 진행한다.
4. 답변 인용은 실제 원답 부분 문자열이어야 하고, 근거 인용은 실제 관측 ID의 내용·대상·상태에 존재해야 한다. 이 검사는 인용의 의미가 맞다는 보증은 아니다.
5. 잘린 출력·거절·gold 문제·검증 실패 시 중단한다. 인용 형식만 잘못된 본 평가 응답에는 아래에 기록한 제한적 보정 1회를 허용한다. 실패를 에이전트 0점으로 처리하거나 부분 완료 평균을 전체 점수로 표시하지 않는다.

검증용 20건도 Codex가 만든 작은 통제 집합이다. 독립적인 사람 검증, 실운영 대표성 또는 완전한 Judge 정확도를 입증하지 않는다. 외부 모델 계열을 사용하면 동일 모델의 자기평가 문제를 줄일 수 있으나 모델 편향을 제거하지는 않는다.

## 호출과 비용

Spring 운영 서비스는 변경하지 않는다. `scripts/haiku_rejudge.py`가 저장된 결과를 읽고 공식 Anthropic Messages API를 직접 호출한다. 운영 에이전트 재실행, 운영 도구 실행, 외부 검색은 채점 중 수행하지 않는다.

- 모델: `claude-haiku-5-5`, effort `medium`, 출력 한도 4096토큰.
- Haiku 5.5 공식 문서에 따라 temperature/top_p/top_k를 보내지 않는다.
- 표준 단가: 요청당 입력 100,000토큰 이하에서 입력 $0.10/백만, 출력 $0.50/백만. 추론 토큰도 응답 usage에 포함된 출력 토큰으로 집계한다.
- 자동 Batch·캐시 쓰기는 사용하지 않는다. 호출 전 보수적 입력 크기와 최대 출력으로 비용을 예약하고, 응답 usage로 누적 사용료를 갱신한다.
- 캠페인 예상 사용료 $2, 최대 240회 시도. 소스·지침·검증 입력 해시를 고정한다.
- API 오류를 자동 재시도하지 않는다. 통신 중단으로 결과가 불명확한 요청은 원장에 남기고 중복 호출을 막는다. 정상 응답은 저장하여 재개할 때 다시 결제하지 않는다.
- `requests.jsonl`에 호출/응답/usage/예상 비용, `cost.json`에 누적값, `raw/`에 응답을 보관한다. API 키는 출력·결과 파일에 저장하지 않는다.
- 비용은 공개 단가로 계산한 추정 API 사용료다. 세금, 크레딧 구매액, 계정의 다른 작업, 최종 청구 금액과는 구분한다.

## 진행 중 검증 기록

- 인증 및 모델 접근 확인 완료. 검증용 20건 모두 사전 판정과 일치했고, 사용료 추정은 $0.0073917이었다.
- 본 평가 11번째 응답에서 근거 인용에 생략기호가 들어가 엄격한 인용 검사가 중단시켰다. 저장된 응답에 한해 JSON 따옴표 이스케이프를 해석하고, 생략기호로 연결된 각 조각이 같은 원문에 순서대로 존재하는지 검사하도록 파서를 보강했다. 답변 인용은 여전히 연속된 부분 문자열이어야 한다.
- 기존 30개 응답의 점수·단정 판정이 동일함을 확인했다. 실패한 응답은 추가 API 호출 없이 복구했고, 원본 응답·기존 구현·새 구현·해시 변경 이력을 보관했다. 모델 지침·입력·모델의 의미 판정은 바꾸지 않았다. 인용 자체를 새로 작성하거나 없는 내용을 보충하지 않는다.
- 인용 처리 보강 후 로컬 테스트 13개 통과. 이 변경과 테스트 결과는 `manifest.json`의 parser revision과 `implementation/`에 추적 가능하게 남겼다.
- 20번째 응답에서는 JSON 개행과 직렬화된 로그 문자열 표기를 원문 내용과 비교하도록 확장했다. 기존 39개 응답의 판정은 그대로였다.
- 22번째 응답은 인용 칸에 `with values`라는 설명을 섞어 기계적인 이스케이프 해석만으로 처리할 수 없었다. 이후 인용 오류에 한해 같은 Haiku에 **인용 형식 보정 1회**를 허용한다. 추출값, 근거 지원 여부, 이유, 근거 ID와 순서, 단정 목록 개수, gold 판정은 코드가 원래 값을 유지하고 모델은 바꿀 수 없다. 다시 채점하거나 불리한 판정을 선택적으로 재시도하지 않는다. 이 호출도 동일 비용·횟수 상한에 포함하며 원본과 보정 응답을 모두 남긴다.
- 보정 정책 적용 전 41개 응답의 판정이 유지됨을 확인했다. 보정 모델이 값을 추가하거나 근거 ID를 바꾸면 거부하는 검사를 포함해 로컬 테스트 16개가 통과했다. 정책 변경 시점과 기존/새 코드 해시는 manifest에 남긴다.
- 첫 캠페인의 29번째 본 평가 응답은 DNS 정답이 잘못됐다고 지적했다. 확인 결과 실제 탐색은 `match[]` 필터를 지원하지만 NumericEvalWorld의 관측 기록이 `query` 파라미터만 남겨 탐색 필터를 누락했다. 데이터셋에는 DNS 메트릭이 있고 다른 arm이 5.1초를 실제 조회했다. 정답 오류가 아니라 평가자에게 제공한 trace 맥락 누락이었다.
- 이를 무시하고 계속하지 않고 첫 캠페인을 참고 자료로 격리했다. 두 번째 캠페인은 모든 답변에 동일한 trace 계약과 reference metric catalog를 제공하며, catalog 자체는 에이전트의 조회 근거로 인정하지 않도록 명시했다. 이전 비용도 $2 한도에 합산했다.
- 두 번째 캠페인의 네 번째 검증에서 같은 `7.45058 GiB ≈ 8 GB` 답변을 틀렸다고 판단했다. 첫 캠페인에서는 통과했다. 두 호출의 system·payload는 같으며 단위가 명확한 동등 물리량 변환을 허용하는 지침도 동일하다. 반복 판정 불일치가 확인되어 사전 설정한 20/20 통과 게이트에 따라 중단했다. 실패가 사라질 때까지 재호출하거나 합격 기준을 낮추지 않았다.

공식 자료: [모델·가격](https://platform.claude.com/docs/en/models/haiku-5-5/overview), [호출 설정 변경 사항](https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide).

## 실행

```bash
rtk proxy python3 scripts/haiku_rejudge.py prepare --out eval/haiku-review-20261117
rtk proxy python3 scripts/haiku_rejudge.py calibrate --out eval/haiku-review-20261117
rtk proxy python3 scripts/haiku_rejudge.py run --out eval/haiku-review-20261117
```

API 키는 환경변수 또는 프로젝트 `.env`의 `ANTHROPIC_API_KEY`에서 읽는다. 기존 출력 디렉터리는 prepare로 덮어쓸 수 없다. 검증을 실패한 캠페인은 재개해도 품질 게이트를 건너뛸 수 없다.
