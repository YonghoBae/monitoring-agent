# 홈서버 관제 평가 — 검증된 범위와 결과

자동 채점 결과로는 이 고정 회귀 시험의 사전 우열 판정 조건을 충족하지 못했다. 이는 동등함을 입증한 결과가 아니다. 아래 점수는 명시된 시험에 대한 결과이며, 전체 홈서버 정확도나 일반적인 하네스 순위가 아니다.

자동 채점 420회 중 35회가 무효였고, 26개 답변에 영향을 주었다. 판정 불일치까지 포함한 미해결 답변은 38/210개다. 두 번의 유효한 지지가 있어야 항목 점수를 주므로, 아래 점수를 오류 없는 확정 정확도로 해석하지 않는다.

사전계획 1차 독립 AI 검수와 자동 채점 두 번의 최종 판정이 모두 일치한 표본은 49/70개다. 완전 일치가 아닌 표본은 21개, 모호한 표본은 3개다. 이 검수 한계를 고려해 위 우열 판정은 자동 채점에 따른 조건부 결과로 해석한다.

## 1. 실제로 재현한 장애 원리: 확인용 핵심 시험

공개 사례에서 가져온 PostgreSQL 클라이언트/서버 버전 불일치와 초기 SQL 접근 거부를 격리 컨테이너에서 실행했다. 정상·실패·복구·정보 부족의 8개 관측 조건을 만들고 두 하네스를 각각 3회 실행했다. 같은 사건 전체를 재생한 데이터도, 독립적인 실제 장애 24건도 아니다.

| 하네스 | 요청 항목 점수 | 질문 전체 안정 통과 | 채점 미해결 | 실행 오류 |
|---|---:|---:|---:|---:|
| 실제 Pi | 51/72 (70.8%) | 14/24 (58.3%) | 3 | 0 |
| 우리 간소화 하네스 | 44/72 (61.1%) | 11/24 (45.8%) | 3 | 0 |

상태, 후속 확인 결과, 직접 원인을 모두 질문에 명시했다. 후속 복원/조회 결과가 관측되지 않았으면 모른다고 답해야 한다. 일반적인 컨테이너 종료 코드만으로 특정 초기화 단계가 실패했다고 단정하지 않는다. 두 번의 채점이 모두 각 항목을 지지해야 항목 점수를 주며, 질문 전체 통과에는 근거 없는 주장도 없어야 한다.

핵심 시험의 독립 교차 검수 점수도 함께 남긴다. 자동 점수를 덮어쓰는 값이 아니라, 같은48개 답변을 별도로 검토한 보조 결과다. 통과 범위는 두 검수자의 해석 차이를 반영한다.

| 하네스 | 두 검수자 공통 항목 점수 | 두 검수자의 질문 전체 통과 범위 |
|---|---:|---:|
| 실제 Pi | 54/72 (75.0%) | 18–18/24 |
| 우리 간소화 하네스 | 45/72 (62.5%) | 9–12/24 |

자동 채점과 독립 검수는 일부 후속 조회의 의미 구분과 부가 설명 해석에서 달랐다. 따라서 자동 점수를 사실 정확도의 절대값으로 취급하지 않는다.

## 2. 넓은 상황 범위: 통제된 35문항 회귀 시험

35개 문항·28개 상황 계열·81개 요청 항목을 양쪽에서 각각 3회 실행했다. 출처는 매뉴얼 기반 통제 시나리오 30개, 공개 사례의 장애 유형을 적용한 시나리오 2개, 비식별 운영 스냅샷 3개다. 35개 실제 장애의 해결 기록이라는 뜻이 아니다. 기존 62개 항목 외에 질문이 이미 요청했던 설명·불확실성 19개도 명시적으로 평가한다.

| 하네스 | 주 점수: 계열별 동일 가중치 | 전체 항목 점수 | 원래 62항목 점수 | 엄격한 구조 포함 통과 | 채점 미해결 |
|---|---:|---:|---:|---:|---:|
| 실제 Pi | 53.6% | 48.1% | 54.8% | 28/105 | 19 |
| 우리 간소화 하네스 | 61.8% | 55.1% | 60.8% | 36/105 | 19 |

주 점수 차이(우리 − Pi)는 +8.23%p다. 선택된 28개 계열을 함께 재표집한 민감도 구간은 [-4.86, +21.92]%p다. 이 구간은 선택한 시험 구성에 대한 민감도이며, 전체 홈서버 모집단의 정확도 신뢰구간이 아니다.

주 점수는 문항 안에서 3회 반복을 평균하고, 계열 안에서 문항을 평균한 뒤 28개 계열에 같은 가중치를 준다. 210개 답변이나 420개 채점 판정을 독립적인 실제 장애로 취급하지 않는다. 전체 항목·원래 항목 점수는 같은 검증된 항목 판정의 추가 집계이며, 실패·미해결 답변도 각 분모에 남는다.

숫자 35개 항목은 단위·차원·허용 오차를 결정적 코드로 확인한 뒤 의미·대상·시간 범위·실제 전달 근거도 별도로 확인한다. 나머지 항목은 의미 기반으로 판정한다. 잘못된 출력 형식과 사실 오류를 구분해 기록하며, 형식이 틀렸다는 이유만으로 의미상 맞는 비수치 설명의 항목 점수를 지우지는 않는다.

엄격한 질문 전체 통과에는 요청 형식·스키마의 적합성, 모든 항목 정답, 평가 가능한 상태에서 근거 없는 주장이 없다는 판정, 실행 오류 없음이 모두 필요하다. 항목 점수와 엄격 통과에는 두 유효한 채점 반복의 지지가 필요하다. 별도의 무근거 주장 비율은 검증된 지표가 아니다.

반복별 주 점수 차이: 1회 -1.49%p, 2회 +17.26%p, 3회 +8.93%p.
채점 미해결 건을 양쪽에 가장 불리하거나 유리하게 놓은 차이 범위: -7.24%p, +29.07%p.

시험 내 우열 조건은 계열 민감도 구간의 0 제외, 세 반복의 동일한 방향, 채점 미해결 건을 앞선 쪽에 불리하게 놓아도 유지되는 방향을 모두 요구한다. 이 민감도 분석은 자동 채점 간 미해결을 다루며, 두 자동 채점이 공유한 오판이나 독립 검수와의 불일치를 보정한 결과는 아니다. 핵심 시험의 두 장애 계열에는 이 추론을 적용하지 않고 기술 통계만 제시한다.

실제 작업 방식도 전달된 도구 응답으로 비교했다. 다음은 넓은 회귀 시험의 보조 기술 통계이며, 정확도 지표나 사전 우열 판정의 근거가 아니다.

| 하네스 | 실행시간 중앙값 | 전달된 도구 응답 수 중앙값 | 가장 흔한 첫 도구 |
|---|---:|---:|---|
| 실제 Pi | 36.0초 | 6 | list_metrics (39/105) |
| 우리 간소화 하네스 | 22.9초 | 4 | list_metrics (38/105) |

도구 응답 수에는 캐시에서 전달된 결과도 포함된다. 같은 입력을 반복했다고 백엔드가 매번 재실행됐다는 뜻은 아니다. 시간에는 하네스 시작 비용도 포함되며, 두 하네스의 전체 추론 토큰 수가 같다고 주장하지 않는다.

## 3. 신뢰를 위해 실제로 확인한 것

- 독립 AI 검수자가 작성하고 먼저 고정한 의미 채점 통제 문제 20개 × 3회에서 필수 판정 60/60 일치. 부가 상태 분류는 점수에서 제외했다.
- 별도로 작성한 수치·의미 연결 통제 문제 20개 × 3회에서 최종 판정 60/60 일치. 수치·형식 기대값은 유료 호출 전에 코드로 확인했다. 이 수치는 해당 통제 문제의 일치율이며 모든 답변에 대한 채점기 정확도 추정은 아니다.
- 동일 Qwen 모델·동일 도구·출력/도구/시간 한도로 실제 Pi와 간소화 하네스를 비교했다. 실행 순서는 교차하고, 질문·정답·채점 코드·분석 규칙을 모델 답변 수집 전에 고정했다.
- 채점기에 하네스 이름을 주지 않고, 에이전트에게 실제 전달된 도구 응답만 근거로 제공했다. 백엔드 원본의 숨겨진 정보로 답변을 정당화하지 않는다.
- 모든 문항의 근거 도달성, 수치 허용 오차, 로그 시간 범위·최신 30줄·300자 제한, 정보 없음과 정상의 구분을 사전 검사했다.
- 수치·의미 연결의 이전 전체 검증은 각각 7/60, 8/60, 1/60 미충족으로 남겼다. 마지막 1건은 이미 오답 처리된 답변의 부가 분류 차이였다. 최종 규약은 항목 점수와 완전 통과 여부로 고정하고 새 독립 문제로 검증했다. 부가 분류의 독립적인 환각률·무근거 주장 없는 비율은 인증하거나 순위에 사용하지 않는다. 이전 실패를 통과로 바꾸지 않았다.
- 의미 판단의 두 번 불일치, 잘못된 인용/출력, 실행 오류를 통과로 숨기지 않았다. 실패한 채점기 검증과 중단한 비교도 비용·이력에서 제외하지 않았다.
- 핵심48개 답변은 서로의 판단을 보지 않은 두 AI가 교차 검수했다. 개별 항목 판정은 144/144 일치했고, 근거 없는 주장 여부까지 포함한 전체 판정은 45/48개가 일치했다. 한 명이라도 표현 해석에 주석을 단 답변은 24개다. 양쪽이 명확하다고 보고 판정도 일치한 24개 중 자동 채점 두 번까지 모두 일치한 것은 16개다.
- 넓은 시험은 사전에 정한 70개 답변(모든 35문항·양쪽 하네스·첫 반복)을 별도로 검수했다. 전체 표본에서 독립 판정과 자동 채점 두 번의 항목·엄격 통과 판정이 모두 일치한 것은 49/70개다. 모호한 3개를 제외한 67개에서는 48개가 모두 일치하고 19개는 완전 일치가 아니다. 표본 내 자동 채점 미해결은 15개다. 완전 일치가 아닌 수에는 자동 채점 누락·무효도 포함될 수 있어 이를 곧바로 채점 오류 수로 해석하지 않는다. 사전계획 1차검수는 답변당 독립 AI 한 명이 의미 판정했으며, 수치·형식 검사는 자동 채점과 같은 고정 코드를 사용했다. 이 1차검수만으로는 같은 답변을 여러 독립 검수자가 중복 판정한 설계가 아니므로 검수자 간 일치율을 추정하지 않는다. 자동 점수를 검수 결과로 덮어쓰거나 모호·불일치 답변을 전체 분모에서 제외하지 않았다.
- 독립 검수자는 사람 대신 사용한 AI 서브에이전트다. 사람 검수라고 부르지 않으며, 공통 모델 편향과 출처 선택 편향은 남는다.

### 같은 70개 답변의 사후 보조 교차검수

자동 채점의 무효 출력이 관찰된 뒤, 사전선택된 동일한 70개 답변(모든 35문항·양쪽 하네스·첫 반복)에 검수자 한 명씩을 추가했다. 답변당 두 AI의 판정을 비교한 사후 보조 분석이며 사전등록된 분석은 아니다. 핵심 48개 시험이나 전체 3회 반복 점수와 합산하지 않는다.

수치·형식 합성 전 의미 항목 일치는 156/162개, 같은 고정 코드로 합성한 최종 항목 일치는 161/162개, 엄격한 질문 전체 통과 판정 일치는 69/70개다. 한 명이라도 모호하다고 표시한 답변은 8/70개다.

모호하지 않은 62개 중 두 검수자의 모든 최종 항목과 엄격 통과 판정이 같은 표본은 60개(요청 항목 134개)다. 이 공통 판정 표본과 자동 채점 두 번의 비교는 일치 46/60개, 불일치 8/60개, 누락·무효 6/60개. 자동 채점 둘 중 하나라도 다르면 불일치로, 유효한 두 판정이 없으면 누락·무효로 구분한다. 공통 판정도 사람 정답의 인증은 아니다.

| 하네스 | 같은 첫 반복 자동 계열 점수 | 두 검수자 판정 범위: 계열 점수 | 같은 첫 반복 자동 엄격 통과 | 두 검수자 엄격 통과 범위 |
|---|---:|---:|---:|---:|
| 실제 Pi | 56.5% | 62.5–63.7% | 9/35 | 11–12/35 |
| 우리 간소화 하네스 | 55.1% | 71.4–71.4% | 10/35 | 12–12/35 |

각 하네스의 분모는 같은 첫 반복 35개 답변·81개 요청 항목이며, 28개 계열에 같은 가중치를 준다. 범위의 하한은 두 검수자 모두 인정한 판정, 상한은 한 명 이상이 인정한 판정이다. 서로 다른 검수자의 항목을 합쳐 질문 전체 통과를 만들지 않는다. 이 범위는 검수자 차이이며 진실의 한계나 신뢰구간이 아니다. 모호한 답변도 전체 분모에 남긴다.

이 보조 비교는 같은 고정 70개 표본에만 해당한다. 독립 AI들의 공통 오류 가능성이 남으며, 원래 3회 반복의 자동 점수나 사전 우열 판정 조건을 대체·수정하지 않는다. 모호함과 검수 불일치는 기존 결론의 해석 한계로 함께 남긴다.

## 4. 아직 증명하지 못한 것

재현 시험은 두 PostgreSQL 장애 원리만 직접 입증한다. 네트워크·스토리지·GPU·OOM·인증서 등의 실제 사건 분포나 전체 원인 진단 정확도까지 대표하지 않는다. 반복 횟수는 장애 종류 수를 늘리지 않는다. 비교 대상은 조사·답변 능력이다. 격리 장애의 복구는 재현 스크립트가 수행했으며 에이전트의 자율 복구 실행 능력을 측정한 것은 아니다.

재생 데이터에 제공된 백업 실행/복원 검사 기록이 운영 서버에서도 이미 수집된다는 뜻은 아니다. 현재 도구에는 호스트 커널 사건, 백업·복원 실행 이력, 로그 페이지 조회, 자세한 네트워크·마운트 정보 등의 공백이 있다. [실제 도구 범위와 우선 보완안](EVAL-V5-TOOL-COVERAGE.md)에 구분했다. 운영 관측이 없으면 모델 개선만으로 원인을 확정할 수 없다.

과거 76.7은 이전 항목·채점 방식의 잠정 점수다. 이번 점수와 직접 비교해 성능 향상량이라고 계산할 수 없다. 요구 항목이 충분히 공개되지 않았던 탐색 비교도 확인용 최종 표와 분리했다.
